Muxa

Know which coding agent is waiting on you — and jump to it. Muxa watches the Claude Code, Codex, and Gemini CLI sessions you already run in tmux, tells you the moment one stops for input, a choice, or an error, and takes you straight to its pane. No wrapper, no new terminal.

brew install open330/tap/muxa
muxa init
muxa attend
