# 터미널 협업 그래프

`muxa graph`는 현재 터미널에서 session → window → pane 관계와 협업 메시지를
탐색하는 TUI다. 브라우저, HTTP 서버, 대시보드 설정이 필요하지 않다. SSH에서도
같은 명령으로 실행한다.

```sh
cargo build -p muxa-cli
./target/debug/muxa graph
```

기본적으로 최근 메시지 200개를 불러온다. 시작 범위를 바꾸려면
`muxa graph --limit 500`을 사용한다. `n`으로 이전 기록을 추가로 읽으며 최대
5,000개까지 표시한다. 상단에 불러온 수와 전체 기록 수를 표시한다.

session마다 바깥 영역을 만들고, 그 안에 window별 영역과 pane을 배치한다.
창 간·세션 간 여백을 확보하고, 메시지 연결이 그룹들을 한곳으로 끌어당기지
않도록 그룹 중심을 유지한다. 노드에는 반발력·응집력·감쇠를 적용하여 약 30fps로
움직임을 갱신한다. 처음 열 때도 압축된 배치가 탄성으로 펼쳐지며, `b`로
안정화된 그래프에 다시 충격을 줄 수 있다. pane을 드래그한 뒤 놓으면 관성과
탄성으로 튕겼다가 안정화된다. `p`를 눌렀을 때만 선택한 노드가 고정된다. session/window 노드를 드래그하면 하위 노드도
함께 이동한다. `0`으로 배치와 고정을 초기화한다.

라벨은 터미널의 실제 글자 폭을 고려해 겹치지 않는 자리에 표시한다. 축소되어
밀도가 높을 때는 session/window 이름과 선택된 노드를 우선 표시하고, 확대하면
pane 라벨을 더 보여준다. 메시지 수 라벨은 `e`를 눌러 필요할 때 표시한다.
상단에는 줌 비율과 물리 시뮬레이션 상태가 나온다.

그래프의 노란 테두리는 선택된 노드다. session은 청록색, window는 자홍색,
pane/agent는 녹색이다. 회색 계층선과 메시지 화살표를 함께 표시하며,
요청은 수신자 방향, 응답은 발신자로 돌아오는 청록색 화살표로 구분한다.
연결선의 `req`와 `rep`는 해당 방향으로 오간 요청과 응답 수다.

| 조작 | 동작 |
| --- | --- |
| 방향키 | 그래프에서 해당 방향의 노드 선택 |
| Enter | 선택 노드와 하위 노드가 주고받은 메시지 표시 |
| Tab / Shift+Tab | 그래프·메시지·상세 패널 간 이동 |
| 메시지 패널의 ↑/↓ 또는 j/k | 읽을 메시지 선택 |
| 메시지에서 Enter | 전체 요청·진행 업데이트·응답 상세로 이동 |
| 상세의 ↑/↓, PageUp/PageDown | 본문 스크롤 |
| h/j/k/l | 그래프 화면 이동 |
| + / - | 확대·축소 |
| f / 0 | 화면 맞춤 / 그룹 배치·고정 초기화 |
| Space | 물리 움직임 일시정지·재개 |
| b / p | 노드에 탄성 충격 주기 / 선택 노드 고정·해제 |
| g / e | 그룹 영역 / 선택 노드의 연결별 메시지 수 표시 전환 |
| v | 메시지 패널을 접고 그래프를 넓게 보기 |
| H | session/window/pane 계층선 표시 전환 |
| / | 불러온 기록에서 session/window/참여자/본문 검색 |
| Esc | 검색과 노드 선택을 해제하고 그래프로 돌아가기 |
| r / n | 새로고침 / 이전 기록 추가 |
| ? | 도움말 |
| q / Ctrl+C | 종료하고 원래 터미널 복구 |

마우스도 지원한다. 노드를 클릭하면 관련 메시지를 표시하고, 노드를 드래그하면
위치를 바꾼다. 빈 그래프 영역을 드래그하면 화면을 이동한다. 그래프 위의 휠은
포인터 위치를 중심으로 확대·축소, 메시지와 상세 패널 위의 휠은 해당 내용을 스크롤한다.

저장된 협업 SQLite 기록을 읽기 전용으로 조회하며 5초마다 갱신한다. 노드 배치는
새로고침 후에도 유지하며, 고정하지 않은 노드는 주변 연결에 맞춰 부드럽게
안정화된다. 종료된 pane의 과거 대화도 표시하므로 전체 live pane 목록과는
다를 수 있다. 기록 경로는 선택한 `--config`의 `[collaboration].path`
또는 기본 Muxa 데이터 경로를 따른다. 데몬 재시작이나 웹 대시보드 활성화는
필요하지 않다.

좁은 터미널에서는 그래프와 메시지를 위아래로 표시하고, 상세에 포커스를 주면
메시지 영역을 상세로 전환한다. 최소 크기는 50열 × 14행이다.
